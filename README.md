# slicc-agent

Empty package for SLICC's agent core. It will be rebuilt on pi's `packages/durable`: session storage in wasm SQLite, remoting, compaction, and pi extensions.

```js
import {} from '@ai-ecoverse/slicc-agent';
```

Node ≥ 24. `npm run lint` runs `slicc-lint`. Releases use semantic-release on `main`.
